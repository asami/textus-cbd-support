## Runtime Failure and Correction

The first live `tools/list` call failed with `NoSuchMethodError` for
`CmlOperationField.apply`. Incremental generated classes had been compiled
against a nine-argument local Maven SNAPSHOT while runtime resolution selected
the newer ten-argument local Ivy SNAPSHOT.

A clean compile removed the stale generated bytecode. `scripts/run-server.sh`
was then changed to execute only the sbt-exported `Runtime / fullClasspath`, so
one coherent CNCF SNAPSHOT classpath is used instead of prepending a separately
resolved runtime JAR. The corrected script subsequently exposed all six tools
and completed live component search.

## Human Direction

The human set the desired component-version behavior:

- simplemodeling.org is the default published component collection;
- working components are added through explicit development-directory
  registration;
- all observed versions should remain retrievable;
- without a version, the default view provides development and latest release
  information; and
- the default selection order is development version before release version.

This direction is recorded for promotion through notes, design, static
specification, and executable specification. It is not yet the behavior of the
current no-automatic-winner source-aware retrieval contract.

# Actor Goal projection

The projection names the selected candidate reference and scope. Shared Actors,
independent Goal intent and explicit Actor-Goal and Goal-UseCase relationships
retain exact source references. Display order is deterministic. Labels never
establish a relationship. Unlinked Goals remain visible. The same candidate
drives development trace and Event Storming; a canonical basis is explicitly
labelled separately from accumulated candidate edits.

Executable specification: `ActorGoalProjectionSpec`.

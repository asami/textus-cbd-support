# Cross-model Event Storming projection

Project the selected candidate's source-owned Command, Operation, Aggregate,
Entity, Domain Event, Policy, Component, Query and View records with their
explicit cause, reaction, dependency and context relationships. Actor, Goal,
Use Case and Slice records belong to the same candidate selection. Context
does not become causality. External endpoints retain their owner and reference;
coverage states and limitations remain visible when a family is unavailable.

Executable specification: `EventStormingProjectionSpec`.
